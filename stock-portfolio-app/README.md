# 나의 주식 포트폴리오 (MVP)

가족/지인이 함께 쓰는 개인용 데스크톱 주식 포트폴리오 프로그램. 현재는 Phase 0~2까지 구현된 상태:

- 보유 종목 수동 입력 (증권사별 그룹핑)
- 종목별 적립식 계획 등록 + 예정 회차 자동 생성 (실제 매수는 사용자가 직접 진행)
- 복리 기대수익 시뮬레이션 (기간/금액/가정수익률을 슬라이더로 조정하는 what-if)

증권사 실시간 API 연동, 세금/수수료 반영, 종목 합산 시뮬레이션, 배당 계산은 다음 단계에서 추가 예정.

## 실행 방법

```bash
npm install
npm run dev
```

## 테스트

```bash
npm test
```

`src/renderer/src/domain/` 아래 복리 계산·적립식 스케줄 로직에 대한 유닛테스트가 있습니다.

## 데이터 저장 위치

현재는 SQLite 대신 JSON 파일로 저장합니다 (`app.getPath('userData')/profiles/`). 리포지토리 함수 시그니처(`src/main/store.ts`)를 유지한 채 나중에 실제 DB로 교체할 수 있도록 설계했습니다.
