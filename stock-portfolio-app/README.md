# 나의 주식 포트폴리오 (MVP)

가족/지인이 함께 쓰는 개인용 데스크톱 주식 포트폴리오 프로그램. 현재 구현된 기능:

- **보유 종목** 수동 입력 (증권사별 그룹핑)
- **적립식 계획**: 종목별 계획 등록 + 예정 회차 자동 생성 (실제 매수는 사용자가 직접 진행). 회당 적립을 **금액**(예: 30만원)으로 할지 **수량**(예: 0.5주, 소수점 매수 지원)으로 할지 선택 가능 — 수량 기준이면 가정 수익률만큼 주가도 같이 오른다고 보고 회당 투입 금액이 매달 재계산됨(`projectQuantityContributionGrowth`)
- **포트폴리오 합산 시뮬레이션**: 전 종목 복리 기대수익을 기간/금액/가정수익률 슬라이더로 조정하는 what-if, "세후 보기" 토글로 국내/해외 세율 자동 적용
- **세금/수수료 계산**: 국내 매매차익 비과세, 해외 양도소득세(기본공제 포함), 배당소득세, 환전수수료 — 모두 UI에서 가정값 조정 가능하도록 설계 (`src/renderer/src/domain/tax.ts`)
- **배당 관리**: 배당 기록 입력 + 세후 배당 계산 + **주/월/년별 배당 수익 막대그래프** (최근 12개 구간)
- **매매 이력**: 매수뿐 아니라 **매도**도 기록 가능, 종목별 요약은 순매수 기준으로 집계
- **캘린더**: 매수·매도·배당 지급일 + 적립식 계획의 예정 회차를 한 달력에서 확인. 날짜를 클릭하면 그날의 내역이 아래 목록에 표시됨
- **자산 증식 그래프**: 보유종목 등록일 + 매수/매도 기록으로 계산되는 누적 투입원금(실제 히스토리) 위에, 앱을 열 때마다 하루 1번씩 기록되는 평가금액 스냅샷을 겹쳐서 보여줌. 과거 시세 데이터가 없어 평가금액 자체의 소급 적용은 안 됨 — 그래서 두 선을 분리해서 보여주는 것. 통화가 섞이면 더할 수 없어(환율 미지원) KRW/USD를 각각 별도 카드로 표시
- **관심종목 / 보유종목 실시간성**: 종목 검색/추가, 시세 자동 갱신(장 시간에 맞춰서만 폴링), 갱신될 때마다 가격 셀이 깜빡이는 효과, 국내/미국 장 상태 배지, 종목 아바타(로고 대신 티커 기반 고유 색상 배지)
- **종목 상세 페이지**: 보유 종목 목록에서 종목을 클릭하면 그 종목만의 실시간 시세(자동 갱신 포함), 누적 투입원금·보유수량 추이, 과거 배당 내역을 모아서 봄. 관심종목에서 클릭해도 연결됨 — 같은 티커의 보유종목이 있으면 이 풍부한 화면으로, 없으면 실시간 시세만 보여주는 가벼운 화면으로 자동 분기. 실제 주가 차트(캔들)는 과거 시세 API를 쓰지 않아 제공하지 않음
- **증권사 API 연동 (토스증권 Open API)**: 시세(Market Data) 조회만 사용 — 계좌 조회/주문 채널은 의도적으로 만들지 않음. `API 연결` 탭에서 클라이언트 자격증명 저장 및 연결 테스트 가능

### 시세 자동 갱신 & 장 시간 인식

관심종목/보유종목 페이지에서 "자동 갱신"을 켜면 15초~5분 간격으로 시세를 다시 불러옵니다. 이때 종목 통화(KRW/USD)로 국내(KRX)·미국 증시 중 어느 시장인지 판단해서, **정규장은 물론 장전·장후 시간외까지 포함해 해당 시장이 열려 있을 때만** 실제로 API를 호출합니다(`src/renderer/src/domain/marketHours.ts`). 장이 전부 닫혀 있으면 자동 갱신은 대기 상태로 표시되고, 자격증명 오류 등으로 3회 연속 실패하면 스스로 꺼집니다. 수동 "현재가 새로고침" 버튼은 이 제약과 무관하게 항상 즉시 조회됩니다.

두 페이지가 거의 같은 폴링 로직을 반복하지 않도록 `useAutoRefreshQuotes` 훅으로 공유합니다. 회사 로고는 쓰지 않습니다 — 종목 수가 많고 CSP가 외부 이미지도 막고 있어서, 대신 티커를 해시한 고유 색상 배지(`StockAvatar`)로 가볍게 대체했습니다.

다음 단계 후보: electron-builder를 통한 배포 패키징, 캘린더 알림/리마인더, (기능이 더 늘어나면) 페이지별로 흩어진 시세 폴링을 하나의 공유 스토어로 합치는 리팩터링.

## 실행 방법

```bash
npm install
npm run dev
```

## 테스트

```bash
npm test
```

`src/renderer/src/domain/`(복리 계산·적립식 스케줄·세금·배당·장 시간 판별·캘린더·자산 추이)과 `src/main/broker/`(자격증명 저장, 토스증권 클라이언트) 아래 로직에 대한 유닛테스트가 있습니다. 현재 9개 테스트 파일, 64개 테스트 모두 통과.

## 데이터 저장 위치

현재는 SQLite 대신 JSON 파일로 저장합니다 (`app.getPath('userData')/profiles/`). 리포지토리 함수 시그니처(`src/main/store.ts`)를 유지한 채 나중에 실제 DB로 교체할 수 있도록 설계했습니다.
