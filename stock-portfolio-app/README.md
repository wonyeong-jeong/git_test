# 나의 주식 포트폴리오 (MVP)

가족/지인이 함께 쓰는 개인용 데스크톱 주식 포트폴리오 프로그램. 현재 구현된 기능:

- **보유 종목** 수동 입력 (증권사별 그룹핑)
- **적립식 계획**: 종목별 계획 등록 + 예정 회차 자동 생성 (실제 매수는 사용자가 직접 진행)
- **포트폴리오 합산 시뮬레이션**: 전 종목 복리 기대수익을 기간/금액/가정수익률 슬라이더로 조정하는 what-if, "세후 보기" 토글로 국내/해외 세율 자동 적용
- **세금/수수료 계산**: 국내 매매차익 비과세, 해외 양도소득세(기본공제 포함), 배당소득세, 환전수수료 — 모두 UI에서 가정값 조정 가능하도록 설계 (`src/renderer/src/domain/tax.ts`)
- **배당 관리**: 배당 기록 입력 + 세후 배당 계산
- **매매 이력**: 수동 매수 기록 관리
- **관심종목**: 종목 검색/추가 + 시세 새로고침
- **증권사 API 연동 (토스증권 Open API)**: 시세(Market Data) 조회만 사용 — 계좌 조회/주문 채널은 의도적으로 만들지 않음. `API 연결` 탭에서 클라이언트 자격증명 저장 및 연결 테스트 가능

다음 단계 후보: electron-builder를 통한 배포 패키징, 배당 달력/알림, 관심종목 시세 자동 갱신(폴링), 거래내역 통계.

## 실행 방법

```bash
npm install
npm run dev
```

## 테스트

```bash
npm test
```

`src/renderer/src/domain/`(복리 계산·적립식 스케줄·세금·배당)과 `src/main/broker/`(자격증명 저장, 토스증권 클라이언트) 아래 로직에 대한 유닛테스트가 있습니다. 현재 6개 테스트 파일, 29개 테스트 모두 통과.

## 데이터 저장 위치

현재는 SQLite 대신 JSON 파일로 저장합니다 (`app.getPath('userData')/profiles/`). 리포지토리 함수 시그니처(`src/main/store.ts`)를 유지한 채 나중에 실제 DB로 교체할 수 있도록 설계했습니다.
